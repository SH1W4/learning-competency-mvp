# Demo Script

## Objetivo

Demonstrar o produto em até 3 minutos por meio de uma única história.

## Regra

Não começar pela arquitetura.

Não começar pela blockchain.

Começar pelo problema.

## Roteiro

### 0:00–0:20 — Contexto

Apresentar uma competência que uma organização quer desenvolver.

### 0:20–0:45 — Trilha

Mostrar a trilha curta e as atividades.

### 0:45–1:15 — Evidências

Mostrar as evidências produzidas pela pessoa.

### 1:15–1:40 — IA

Mostrar a interpretação:

- dados extraídos;
- relação com competência;
- sinais;
- itens que exigem revisão.

### 1:40–2:00 — Revisão

Mostrar o humano aceitando/corrigindo/rejeitando a interpretação.

### 2:00–2:20 — Estado

Mostrar o competency state resultante.

### 2:20–2:45 — Solana

Mostrar:

- Credential;
- Schema;
- Attestation;
- referência on-chain.

### 2:45–3:00 — Verify

Outra interface consulta a prova e confirma o estado.

## Resultado visual

O juiz deve conseguir responder sozinho:

> O que entrou?

> O que a IA fez?

> O que o humano decidiu?

> O que foi atestado?

> O que a blockchain acrescentou?
