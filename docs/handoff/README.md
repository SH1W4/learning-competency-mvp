# Handoffs

Esta pasta contém documentos formais de handoff entre marcos do projeto (M1 → M2 → M3 → Interface → M4).

## Propósito

Cada handoff documenta:
- O que foi entregue pelo marco anterior
- Artefatos técnicos e dados
- Pontos de integração
- Limitações e considerações
- Dependências
- Próximos passos

## Formato

Handoffs seguem um template consistente:
- Resumo executivo
- O que foi entregue
- Artefatos técnicos
- Pontos de integração
- Limitações e considerações
- Dependências
- Comandos úteis
- Documentação relacionada
- FAQ
- Próximos passos

## Handoffs disponíveis

- [M3 → Interface](./M3_TO_INTERFACE.md) — Handoff do marco de atestação Solana para a camada de interface

## Uso

Ao assumir um novo marco, o owner deve:
1. Ler o handoff do marco anterior
2. Compreender os artefatos e pontos de integração
3. Esclarecer dúvidas com o owner anterior
4. Planejar a implementação baseada nos pontos de integração
5. Documentar novos handoffs ao concluir o próprio marco
